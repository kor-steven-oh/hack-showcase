# hack-showcase

S.LSI Hello AI Hackathon 온라인 전시관. 아이소메트릭 2D 캔버스 위에서 아바타로 홀을 돌아다니며 해커톤 프로젝트 부스를 관람하는 웹앱입니다. 브라우저 단독(오프라인)으로도 열리고, 동봉된 Node 서버를 띄우면 멀티유저(위치·채팅·메시지 월·랭킹·투표 동기화)로 동작합니다.

## 실행

**멀티유저 (권장)**

```bash
npm install
node server.js   # http://localhost:3210 — 기본으로 화이트 테마 서빙
```

**오프라인 (파일로 바로 열기)** — 네트워크 기능 없이 로컬 동작

```bash
open hello-ai-exhibition-white.html  # 화이트 테마
open hello-ai-exhibition.html        # 다크 테마
```

외부 의존성은 Pretendard 폰트 CDN + 서버용 `ws` 패키지뿐.

## 조작

| 키 | 동작 |
|---|---|
| `W A S D` / 화살표 | 이동 |
| 빈 바닥 클릭 | 클릭 지점으로 이동 (벽에 막히면 그 자리에서 멈춤) |
| 전시 패널·메시지/랭킹 보드 hover/클릭 | 패널 강조 / 해당 모달 바로 열기 |
| `Space` | 가까운 부스 관람 · 스팟 상호작용 (팀 랭킹/미니게임/메시지 월/안내/도슨트) |
| `Esc` | 모달 닫기 |

모바일은 화면 터치패드 지원.

## 구성

- **트랙 존 5개** — 설계·EDA / 수율·품질 / 설비·운영 / HR·People / 개발생산성·DevX. 존마다 2×2 부스, 트랙 색 카펫 + 존 중앙 라운지(쿠션 소파·노트북 6대만 놓인 대형 공동 작업 테이블·닉네임이 표시되는 테이블 착석 방문객 6명·협탁·쿠키/도넛/과일과 음료를 놓은 간식 테이블·착석 NPC). 트랙별 칩·웨이퍼·로봇 팔·사람 형상·코드 괄호 조형물 배치. 중앙 테이블 측면·아래쪽에 소파 3개를 정렬하고 소파 사이 모서리에 간식대와 트랙별 오실로스코프·현미경·설비 진단 장비 또는 낮은 책장을 배치. 소파 옆에는 참가자의 백팩을 배치
- **중앙 광장** — HELLO AI 전광판과 팀 랭킹 보드. 팀별 좋아요 순위를 확인하고 바로 투표
- **프로젝트 모달** — 동일 높이의 데모 영상과 3장 슬라이드형 프로젝트 소개(개요·기술·팀), 상세 HTML 소개서 다운로드
- **트랙 작업 보드·NPC 문답** — 트랙별 위쪽 소파 자리에 가구와 같은 아이소메트릭 방향의 TODO / DOING / DONE 장식 보드. 가까운 라운지의 작업자들이 4초 후 트랙에 맞는 짧은 문답을 시작하고 문답 사이 8초 동안 쉬며, 모달을 열거나 라운지에서 멀어지면 중단. 전체 채팅·서버에는 전송하지 않음
- **입구 굿즈 테이블** — 안내데스크 옆에 트랙별 스티커·접힌 티셔츠·에코백과 보충 상자를 배치
- **메시지 월** — 보드 2개 (T1/T4 사이, T3/T5 사이). 방문객이 한 줄 메시지를 붙이면 서버에 저장되고 전체 유저에게 실시간 공유
- **대형 전광판** — 서쪽 외벽의 야구장 스타일 스크린. 메시지 월 문구를 타자기 효과(타이핑→3초 유지→백스페이스)로 순환 표시
- **플레이그라운드** — 아케이드 캐비닛 6대. 반응속도 미니게임 + 서버 랭킹 TOP 10 (닉당 최고기록)
- **카페 라운지** — 우드 바리스타 카운터에 2그룹 에스프레소 머신·그라인더, 옆 추출대에 입체 목재 프레임·물탱크·원두층·커피 서버·조절 밸브를 표현한 더치커피 기구 2대 배치. 디저트 서비스 라인과 진입부 메뉴 입간판. 중앙 통로와 카운터 앞을 비워 두고 2인석 11세트·4인석 3세트(의자 34개, 다양한 옷 색상의 착석 손님 23명)·러그 위 소파 코너를 배치하고 소형 화분 6개, 테라코타 아치·커피콩 조각·플로어 조명으로 장식. 음료 쿨러 2대와 자판기 1대 배치.
- **전체 채팅** — 멀티유저 실시간 채팅과 캐릭터 머리 위 말풍선(6초). 입장 후 현장 분위기 메시지를 최대 50건 순차 표시하며, 실제 접속자가 10명 이상이면 자동으로 일시 중지
- **안내 도슨트 봇 4대** — 로봇 외형(사각 헤드·바이저·LED)으로 홀을 분산 순찰. 다가가면 멈춰 마주보고, `Space`로 전시관 안내 모달. 안내 멘트를 말풍선으로 순환 출력
- **AI 심사위원단 5명** — 아우라를 두르고 자연스러운 간격의 군집으로 가까운 미관람 부스부터 순회하며, 심사 중 다양한 평가와 짧은 문답을 말풍선으로 출력
- NPC 50명이 닉네임을 달고 배회, 로봇청소기 1대가 통로를 돌며 청소

## 멀티유저 서버

`server.js` — 정적 파일 서빙 + WebSocket 중계 (포트 3210, `PORT` 환경변수로 변경).

- **위치 동기화**: 클라이언트 10Hz 전송 → 서버가 5Hz·12×12 공간 셀 기반 관심영역(AOI) 스냅샷으로 묶어 주변 사용자에게만 전송. 혼잡 구역은 가까운 150명으로 동기화하고, 클라이언트는 전체 스냅샷으로 AOI 이탈 사용자를 정리하며 보간·화면 컬링·가까운 120명 렌더링 적용. 연결이 끊기면 지수 백오프로 자동 재접속
- **채팅**은 실시간 중계만 수행. **메시지 월 / 반응속도 랭킹 / 팀 좋아요**는 중계·영속화 (`idea-notes.json`, `reaction-scores.json`, `team-likes.json` — 파일 DB, gitignore)
- **500명 대비**: 공간 셀 기반 위치 동기화, 30초 ping/pong 하트비트, `bufferedAmount` 백프레셔, 입퇴장 렌더 목록 갱신 배치, 채팅 DOM 200개 상한

## 파일 구조

| 파일 | 역할 |
|---|---|
| `js/theme.js` | 캔버스 테마 팔레트 |
| `js/data.js` | 트랙 정의 + 샘플 전시 데이터 |
| `js/world.js` | 지오메트리 · 부스/장식 배치 · 바닥/벽 · 충돌 |
| `js/render.js` | 캔버스 draw 함수 · 전광판 타자기 효과 · 미니맵 · 렌더 |
| `js/main.js` | 플레이어/NPC/AI 심사위원/로봇청소기 · 입력 · 게임 루프 · 모달 · 미니게임 · 채팅 |
| `js/net.js` | WebSocket 클라이언트 (`NET`) — 위치/채팅/노트/랭킹/좋아요 동기화와 실제 접속자 수 제공. file:// 로 열면 조용히 오프라인 |
| `server.js` | 정적 서빙 + WS 중계 서버 |
| `exhibition.css` | 스타일. 테마 색은 CSS 변수 (`:root` 다크, `[data-theme="white"]` 오버라이드) |
| `hello-ai-exhibition*.html` | 얇은 진입점 (마크업만, `data-theme`과 title만 다름). 스크립트 로드 순서 유지 필요 |
